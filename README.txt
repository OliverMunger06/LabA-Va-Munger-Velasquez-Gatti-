# CineMax - Sistema di Gestione Cinema

Progetto didattico per la gestione automatizzata delle attività di una struttura cinematografica.

## ----- Funzionalità Principali -----

***Autenticazione & Ruoli: Gestione accessi multi livello per *Cliente*, *Bigliettaio* e *Proiezionista*.
***Gestione Palinsesto e Proiezioni: Caricamento e consultazione dei film e delle proiezioni in programmazione.
***Prenotazione Biglietti: Sistema di scelta e acquisto/prenotazione posti per i clienti registrati.
***Persistenza Dati: Salvataggio e lettura continua delle informazioni tramite file CSV.

## ------------ Requisiti ------------

***Sistemi Operativi: Windows 11, macOS e Linux (cross-platform supportato da Java)
***Java Development Kit (JDK): Versione 16 o superiore
***IDE consigliato: IntelliJ IDEA / Eclipse

## ---- Come Eseguire il Progetto ----

1. Scarica la repository sul tuo computer.
2. Apri la cartella del progetto con il tuo IDE (es. IntelliJ IDEA).
3. Assicurati che la cartella `data/` contenente i file CSV sia presente nella radice del progetto.
4. Naviga fino al file `src/cinemax/CineMax.java`.
5. Esegui la classe principale (`Run 'CineMax.main()'`).
